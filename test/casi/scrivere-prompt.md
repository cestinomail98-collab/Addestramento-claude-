# Caso: scrivere-prompt

**Skill provata:** `scrivere-prompt`

## Prompt da inviare

```
Mi scrivi un prompt per far fare a Claude le descrizioni dei prodotti del mio negozio online?
```

## Cosa ci si aspetta da una risposta buona
- Fa **poche domande mirate** (tipo di prodotti, pubblico, lunghezza, tono, dati disponibili)
  oppure dichiara le ipotesi che fa e le rende facili da cambiare.
- Il prompt prodotto contiene: obiettivo, contesto sul negozio e sui clienti, posto per i dati del
  prodotto (tra tag), vincoli di lunghezza e tono, un esempio, il formato di uscita.
- Chiede di non inventare caratteristiche che non sono nei dati del prodotto.

## Segnali di risposta scadente
- Un prompt di una riga tipo "Scrivi una descrizione accattivante per {prodotto}".
- Istruzioni in maiuscolo o piene di "DEVI".
- Nessun accenno a cosa fare quando mancano informazioni.
